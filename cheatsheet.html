Program skeleton

Every executable program has one main. Indentation defines blocks; there are no braces and no semicolons.

def main() -> Int32
    name: String = "world"
    print(f"hello {name}")
    return 0

    print("yes")

Functions, purity and classes

Use puredef when a function must not print, read input, write globals, call a native module or start a thread. Purity is checked at compile time.

def add(a: Int32, b: Int32) -> Int32
    return a + b

puredef square(x: Int32) -> Int32
    return x * x

class Counter:
    n: Int32

    def __init__(self, start: Int32)
        self.n = start

    def next(self) -> Int32
        self.n += 1
        return self.n

Unions

A union value is one of its listed types. It is not an Any escape hatch: the compiler checks every member. There are no traits and no user-defined generics in the language.

from unions import Number

def show(v: Number)
    if isinstance(v, Int32):
        print(v + 1)
    elif isinstance(v, String):
        print(strings.upper(v))

show(Int32(7))
show("tiny")
