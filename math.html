Math

numbers, roots and prime tests

What it does

Pure-Threadon math helpers. No external toolchain is needed. Integer and float functions have different names because Threadon has no overloading.

Example

A short program using the module:

import math

def main() -> Int32
    print(math.pow_int(2, 10))
    print(math.gcd(48, 18))
    print(math.sqrt_f(81.0))
    print(math.factorial(10))
    return 0
1024 6 9.000000 3628800

API

FunctionResult
abs(n), iabs(n)Int32 absolute value; both are pure
pow_int(base, exp)integer power by repeated squaring; negative exponent gives 0
factorial(n)n! as an Int64
gcd(a, b), lcm(a, b)greatest common divisor / least common multiple
sign(n), is_prime(n), integer_sqrt(n)sign, trial-division primality, integer square root
trunc_f(x), floor_f(x), ceil_f(x), round_f(x)rounding to an Int64
sqrt_f(x), hypot_f(a, b)square root and hypotenuse
pi(), e()constants as Float64
to_radians(d), to_degrees(r)angle conversion
clamp_f(x, lo, hi), lerp_f(a, b, t)range limit and interpolation

Notes and gotchas

  • round_f rounds half up for positive values; negative halves round towards zero.
  • sqrt_f uses a fixed number of Newton iterations and returns 0.0 for non-positive input.
  • Integer arithmetic wraps in Threadon, so pow_int and factorial can overflow silently.
