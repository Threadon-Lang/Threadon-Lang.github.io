Vector

2D and 3D vectors

What it does

Two- and three-dimensional vectors of Float64. Vec2 and Vec3 are structs, so they use named field initializers and value semantics. Structs have no methods in Threadon, so operations are plain functions that return new vectors.

Example

A short program using the module:

from vector import Vec2, add2, length2

def main() -> Int32
    a: Vec2 = Vec2(x=3.0, y=4.0)
    b: Vec2 = add2(a, Vec2(x=1.0, y=2.0))
    print(length2(a))
    print(b.x)
    return 0
5.000000 4.000000

API

FunctionResult
vec2(x, y), vec3(x, y, z)constructor functions
add2, sub2, scale22D sum, difference, scalar multiple
dot2, length2, normalize2, distance22D products and measures
add3, sub3, scale33D sum, difference, scalar multiple
dot3, cross3, length3, normalize3, distance33D products and measures

Notes and gotchas

  • Normalizing the zero vector returns the zero vector.
  • Built on math.sqrt_f; results are approximate like any float.
