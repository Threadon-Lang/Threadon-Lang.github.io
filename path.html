Path

POSIX path string helpers

What it does

String utilities for POSIX-style paths, built on the strings module. They never touch the disk and never check whether a path exists.

Example

A short program using the module:

import path

def main() -> Int32
    p: String = "/home/user/notes.txt"
    print(path.basename(p))
    print(path.extension(p))
    print(path.join("a", "b"))
    return 0
notes.txt .txt a/b

API

FunctionResult
basename(p)last component
dirname(p)everything before the last slash; . when there is none
extension(p)suffix including the dot, or ""
stem(p)file name without extension
with_extension(p, ext)replace the extension
join(a, b)join with one slash; an absolute b replaces a
is_absolute(p)does p start with /?
normalize(p)collapse repeated slashes and drop a trailing slash

Notes and gotchas

  • Use forward slashes; Windows drive letters and backslashes are not handled.
  • normalize does not resolve .. segments.
