Date

Gregorian calendar arithmetic

What it does

Dates are surprisingly fiddly. This module uses the standard civil-calendar algorithms to convert between YYYY-MM-DD strings and a count of days since 1970-01-01, then builds weekdays and date arithmetic on top. Years must be 1 or greater.

Example

A short program using the module:

import date

def main() -> Int32
    print(date.is_leap(2000) and not date.is_leap(1900))
    print(date.add_days("2024-02-28", 1) == "2024-02-29")
    return 0
True True

API

FunctionResult
is_leap(year)is it a Gregorian leap year?
days_in_month(year, month)28..31, or 0 for a bad month
days_from_civil(y, m, d)days since 1970-01-01 as Int64
civil_from_days(z)ISO YYYY-MM-DD text
weekday(y, m, d)0 = Monday, 6 = Sunday
add_days(s, delta), days_between(a, b)shift a date and measure a gap

Notes and gotchas

  • There is no clock or timezone here; use the native time module if you need real time.
  • Invalid ISO strings in add_days are treated as 1970-01-01.
