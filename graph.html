Graph

directed graphs and BFS

What it does

Graphs are useful for routes, dependencies and many other puzzles. A Graph has a fixed number of nodes numbered 0..n-1, directed edges, and value semantics: adding an edge returns a new graph. Traversal is iterative, so it does not use the call stack.

Example

A short program using the module:

import graph

def main() -> Int32
    g: graph.Graph = graph.empty(3)
    g = graph.add_edge(g, 0, 1)
    g = graph.add_edge(g, 1, 2)
    print(graph.has_path(g, 0, 2))
    return 0
True

API

FunctionResult
empty(n)graph with n nodes and no edges
add_edge(g, u, v), remove_edge(g, u, v)new graph with the edge added or removed
neighbors(g, u), has_edge(g, u, v)outgoing edges and direct-edge test
bfs(g, start)shortest distances; -1 when unreachable
has_path(g, start, goal)is the goal reachable?
reachable(g, start)reachable node indices in ascending order

Notes and gotchas

  • Out-of-range node indices are ignored rather than treated as errors.
  • Edges are stored as two flat lists (from and to) to keep the generated IR simple.
