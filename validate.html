Validate

string format checks

What it does

Input from input() or a native module arrives as text. These helpers answer the narrow question "does this string have the right shape?" before you try to use it. They never throw and never modify the string.

Example

A short program using the module:

import validate

def main() -> Int32
    print(validate.is_ipv4("127.0.0.1"))
    print(validate.luhn("4111111111111111"))
    return 0
True True

API

FunctionResult
is_int_string(s)optional sign, then digits only
is_float_string(s)sign, one dot, digits before the dot
is_ipv4(s)four 0..255 octets without leading zeros
is_hex_color(s)# plus six hex digits
is_email_like(s)one @, a dot in the domain, no spaces
luhn(s)digits only, length at least 2, checksum passes

Notes and gotchas

  • These are format checks, not proof that an address exists or that a number is in range for a cast.
  • is_email_like is deliberately permissive; it does not implement RFC 5322.
