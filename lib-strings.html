Strings

case, search, split and pad

What it does

The language gives strings concatenation, indexing, slicing and comparison. This module adds the everyday helpers. Strings are immutable, so every function returns a new value. Indexes count bytes, just like len(s) and s[i].

Example

A short program using the module:

import strings

def main() -> Int32
    s: String = strings.trim("  Hello, World!  ")
    print(strings.upper(s))
    parts: List[String] = strings.split(s, ", ")
    print(strings.join(parts, " | "))
    return 0
HELLO, WORLD! Hello | World!

API

FunctionResult
length(s), ord(c)length as Int64; byte value of a one-byte string
upper(s), lower(s)ASCII case conversion
trim(s), ltrim(s), rtrim(s)remove surrounding whitespace
index_of(s, needle), last_index_of(...)match position, or -1
contains(s, needle), count(s, needle)membership and match count
starts_with(s, prefix), ends_with(s, suffix)affix tests
replace(s, old, new)replace every occurrence
split(s, sep), join(parts, sep)split into / join from a List[String]
reverse(s), repeat(s, n)reverse or repeat text
pad_left(s, width, pad), pad_right(...)pad to a minimum width
is_digit(s), is_alpha(s), is_alnum(s)whole-string character tests

Notes and gotchas

  • Case conversion is ASCII only; Threadon strings are byte strings.
  • split(s, "") returns a one-element list containing s.
  • ord(c) returns -1 for an empty or multi-byte string.
