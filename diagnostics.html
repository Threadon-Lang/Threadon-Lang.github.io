Threadon / Diagnostics

Diagnostics

one clean line, once

Message shape

All compiler diagnostics go through compiler/threadon/errors.py. A compile-time error has one plain shape:

Error: MESSAGE at line N

With a known source position the renderer adds the source line and a caret. Warnings use Warning: and notes use Note:. The compiler prints the message once; it does not dump LLVM IR, Python tracebacks or duplicate Error: prefixes.

Color and scripts

Colors are optional. NO_COLOR=1 disables them; FORCE_COLOR=0 does the same. On a terminal the label is colored and bold, but the text is otherwise identical. Redirecting output should not change what a script can parse.

Common messages

MessageMeaning
Error: Cannot redefine builtin/standard library function 'collect'A program tried to declare a function such as collect, input or print. Builtins and auto-imported stdlib functions are reserved.
Error: ... at line 12A parser, checker or IR-builder error. Fix the reported line first; later errors are often consequences.
Error: no function 'main' found in the compiled moduleThe source compiled, but there is no entry point to run or link.
Error: Type mismatch ...The checker rejected an operation. Threadon does not insert implicit conversions; use an explicit cast.
Error: invalid TOML ...The project config used unsupported syntax. Keep to sections, strings and string arrays.

Compile-time versus runtime

Runtime errors from a generated program are emitted by LLVM code and keep their own message strings. They are deliberately not wrapped in Error:, because they are not compiler diagnostics. Use debug mode to turn some silent undefined behavior into explicit runtime checks, and --flag-inf for non-finite floats.

Reporting a problem

  • Copy the whole diagnostic, including the line number and caret line.
  • Include the smallest source file that reproduces it.
  • Say which command you ran and whether you used the repo compiler or an installed package.
  • For benchmark or cache problems, include the relevant threadon.toml and threadon.lock.
