Questions and answers

Why no traits, generics or Any?

Threadon is deliberately C-like. Concrete types and unions keep the generated IR simple and the diagnostics predictable. A union is closed polymorphism: the compiler knows every member and checks every use. There is no open-ended Any union and no user-defined generics.

Is pattern matching on unions coming?

It is the next planned language feature after the project system. Until then, narrow a union with explicit type tests, as shown on the cheatsheet and the Unions page.

Why is collect() explicit?

There is no background collector and no allocation threshold. A call runs a full conservative mark-and-sweep on the calling thread. That makes pauses visible and keeps the runtime small; see Garbage collector.

Why is the JIT so much slower than the native executable?

The benchmark times fresh processes. A JIT run pays Python compiler startup plus lli -O2 startup on every launch. The native executable pays compilation once and then runs generated machine code directly. Compare the rows on Benchmarks.

Why are lists copied when passed to a function?

Value semantics make ownership obvious: a helper cannot resize your list behind your back. Functions in the bundled libraries return new lists. For tight loops, keep the work in one function so no copies are made.

Why byte strings instead of Unicode strings?

String indexing and len(s) count bytes, which matches the LLVM representation. The strings module is ASCII-oriented. Non-ASCII text can be stored, but there is no UTF-8 iteration layer.

Why no catchable exceptions?

There is no exception unwinding in the generated IR. Errors are either compile-time diagnostics or explicit runtime checks; see Exceptions.

Where do dependencies come from?

Only local directories listed in threadon.toml. There is no registry and no network fetch. Projects explains the cache and lockfile.

Can I call C, C++, Rust or Python code?

Yes. Native modules are declared in manifests and built by the importer; Python classes use the embedded bridge. See Classes and Imports.

Which compiler should I use for docs examples?

Use the repository compiler with PYTHONPATH=compiler python3 -m threadon. An installed package can be older than the checkout and may give different diagnostics.
