Bitops

bitwise operations for UInt32

What it does

Threadon has no &, |, ~, << or >> operators. This module implements them for UInt32 by peeling bits off with division and modulo. The results are correct but slower than hardware instructions.

Example

A short program using the module:

import bitops

def main() -> Int32
    print(bitops.band(UInt32(12), UInt32(10)))
    print(bitops.shl(UInt32(1), 5))
    print(bitops.bnot(UInt32(0)))
    return 0

API

FunctionResult
band(a, b), bor(a, b), bxor(a, b)bitwise AND, OR, XOR over 32 bits
bnot(a)bitwise NOT
shl(a, n), shr(a, n)shift left/right by n bits
pow2(n), full()power of two; all bits set
popcount(a)number of set bits, as Int32
bit(a, n)is bit n set?
set_bit, clear_bit, toggle_bitreturn a new UInt32 with one bit changed
trailing_zeros(a)count of trailing zero bits (32 for zero)

Notes and gotchas

  • All arguments and results are UInt32; write UInt32(...) explicitly.
  • Shifts wrap: bits shifted past the top are discarded.
