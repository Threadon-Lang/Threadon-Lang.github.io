How to use this page

This page collects the short example from every bundled library in one place. Each recipe links to the full page with its API table and output. The snippets are the same ones used to generate the library documentation, so they stay in sync with the reference.

Recipes

Math

Integer and float math helpers: powers, factorials, gcd/lcm, rounding, square roots and constants. Full reference: Math. The documented output is on that page.

import math

def main() -> Int32
    print(math.pow_int(2, 10))
    print(math.gcd(48, 18))
    print(math.sqrt_f(81.0))
    print(math.factorial(10))
    return 0

Strings

String helpers for case conversion, trimming, searching, splitting, joining, replacing and padding. Full reference: Strings. The documented output is on that page.

import strings

def main() -> Int32
    s: String = strings.trim("  Hello, World!  ")
    print(strings.upper(s))
    parts: List[String] = strings.split(s, ", ")
    print(strings.join(parts, " | "))
    return 0

Lists

Helpers for List[Int32] and List[String]: sums, extremes, searching, sorting, reversing and joining. Full reference: Lists. The documented output is on that page.

import lists

    print(lists.sort_int(xs))
    print(lists.sum_int(xs))

    return 0

Random

import random

def main() -> Int32

    print(random.randint(1, 6))
    print(random.rand_float())
    return 0

Path

Basename, dirname, extension, join and normalize for path strings — no filesystem access. Full reference: Path. The documented output is on that page.

Vector

Vec2 and Vec3 structs with addition, dot and cross products, lengths, normalization and distances. Full reference: Vector. The documented output is on that page.

from vector import Vec2, add2, length2

def main() -> Int32
    a: Vec2 = Vec2(x=3.0, y=4.0)
    b: Vec2 = add2(a, Vec2(x=1.0, y=2.0))
    print(length2(a))
    print(b.x)
    return 0

Containers

Functional stacks, queues and Dict-backed maps with String keys and values, built for Threadon's value semantics. Full reference: Containers. The documented output is on that page.

import containers

def main() -> Int32
    ages: containers.StringIntMap = containers.empty_string_int_map()
    ages = ages.put("ann", 30)
    ages = ages.put("bob", 40)
    found: containers.IntLookup = ages.get("bob")
    print(found.found)
    print(found.value)
    print(ages.size())
    return 0

IntSet

A functional set with add, remove, union, intersection and difference. Full reference: IntSet. The documented output is on that page.

import intset

def main() -> Int32
    a: intset.IntSet = intset.from_list([1, 2, 3])
    b: intset.IntSet = intset.from_list([3, 4])
    print(intset.size(intset.union(a, b)))
    print(intset.contains(a, 2))
    return 0

Base64

RFC 4648 base64 encoding and decoding for strings and byte lists, written in pure Threadon. Full reference: Base64. The documented output is on that page.

import base64

def main() -> Int32
    print(base64.encode("hello") == "aGVsbG8=")
    print(base64.decode("aGVsbG8=") == "hello")
    return 0

URL

Percent-encode strings, decode them again, and build or parse application/x-www-form-urlencoded query strings. Full reference: URL. The documented output is on that page.

import url

def main() -> Int32
    print(url.quote("a b&c") == "a%20b%26c")
    print(url.unquote("a+b%2Fc") == "a+b/c")
    return 0

Checksum

FNV-1a, Adler-32 and CRC-8 checksums for strings and byte lists, with deterministic integer results. Full reference: Checksum. The documented output is on that page.

import checksum

def main() -> Int32
    print(checksum.fnv1a("hello") == checksum.fnv1a("hello"))
    print(checksum.adler32("hello") > 0)
    return 0

Complex

A Complex struct plus add, subtract, multiply, scale, conjugate, magnitude and text conversion helpers. Full reference: Complex. The documented output is on that page.

import complex

def main() -> Int32
    z: complex.Complex = complex.make(3.0, 4.0)
    print(complex.norm(z) == 25.0)
    w: complex.Complex = complex.mul(z, z)
    print(complex.norm(w) == 625.0)
    return 0

Heap

import heap

Graph

A small directed graph type with edge insertion/removal, neighbours, reachability and breadth-first distances. Full reference: Graph. The documented output is on that page.

import graph

def main() -> Int32
    g: graph.Graph = graph.empty(3)
    g = graph.add_edge(g, 0, 1)
    g = graph.add_edge(g, 1, 2)
    print(graph.has_path(g, 0, 2))
    return 0
