IntSet

a set of Int32 values

What it does

A set of Int32 values backed by a list and wrapped in an IntSet class. Like Containers, it uses a functional API: every operation returns a new set and leaves the input untouched.

Example

A short program using the module:

import intset

def main() -> Int32
    a: intset.IntSet = intset.from_list([1, 2, 3])
    b: intset.IntSet = intset.from_list([3, 4])
    print(intset.size(intset.union(a, b)))
    print(intset.contains(a, 2))
    return 0
4 True

API

FunctionResult
empty_set()a new empty set
from_list(xs)set of the distinct values in an integer list
to_list(s)values as a List[Int32], in insertion order
contains(s, v), size(s)membership and size
add(s, v), remove(s, v)new sets with the value added or removed
union(a, b), intersection(a, b), difference(a, b)new sets from two sets

Notes and gotchas

  • There is only an Int32 set; Threadon has no overloading or user-defined generics.
  • Membership is a linear scan, so large sets are slow.
