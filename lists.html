Lists

search, sort and aggregate lists

What it does

Threadon lists support append, pop, insert, remove and indexing, but not search or sort. There is no overloading, so each helper has an _int or _str suffix. Lists are passed by value; functions here return new lists and leave their inputs alone.

Example

A short program using the module:

import lists

def main() -> Int32
    xs: List[Int32] = [5, 1, 4, 1, 3]
    print(lists.sort_int(xs))
    print(lists.sum_int(xs))
    print(lists.unique_int(xs))
    return 0
[1, 1, 3, 4, 5] 14 [5, 1, 4, 3]

API

FunctionResult
range_list(n)[0, 1, ..., n-1]
sum_int(xs)sum as Int64
min_int(xs), max_int(xs)extremes, or 0 for an empty list
contains_int(xs, v), index_int(xs, v)search; index_int returns -1 if absent
count_int(xs, v)number of matches
sort_int(xs), sort_str(xs)new ascending list (stable insertion sort)
reverse_int(xs), reverse_str(xs)new reversed list
unique_int(xs)first copy of each value
extend_int(xs, more)new list with more appended
join_int(xs, sep)text such as 1-2-3
contains_str, index_str, count_strstring-list equivalents

Notes and gotchas

  • Passing a list to a function copies it. A helper cannot resize the caller's list.
  • Sorting and reversing allocate a new list; large lists cost time and memory.
