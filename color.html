Color

RGB values and hex colors

What it does

Colors are just three integers, but the small details (clamping, hex text, perceived brightness) come up repeatedly. This module wraps them in a RGB struct and pure functions that always return values in the 0..255 range.

Example

A short program using the module:

import color

def main() -> Int32
    c: color.RGB = color.from_hex("#336699")
    print(color.to_hex(c) == "#336699")
    return 0
True

API

FunctionResult
make(r, g, b)clamp three channels into an RGB
from_hex(s)parse #RRGGBB or RRGGBB; invalid text is black
to_hex(c)lowercase #rrggbb text
brightness(c)weighted brightness from 0 to 255
mix(a, b, t)linear blend with t in 0..1
is_dark(c)is the brightness below 128?

Notes and gotchas

  • All inputs are clamped, so an out-of-range channel cannot produce invalid hex output.
  • No color space conversion is attempted; this is plain sRGB-style arithmetic.
