Heap

functional min-heap and heapsort

What it does

A heap gives fast access to the smallest element without sorting the whole collection. This implementation stores the heap in a flat List[Int32] and returns a new Heap after each change, matching Threadon's value semantics.

Example

A short program using the module:

import heap

def main() -> Int32
    out: List[Int32] = heap.sort([3, 1, 2])
    print(out[0] == 1 and out[2] == 3)
    return 0
True

API

FunctionResult
empty()a new empty heap
from_list(xs)heap containing every value in a list
size(h), peek(h)item count and smallest value (0 when empty)
push(h, v)new heap with v added
pop(h)new heap without the smallest value
sort(xs)ascending list via heapsort

Notes and gotchas

  • To read the value you are about to remove, call peek(h) before pop(h).
  • Popping an empty heap returns it unchanged.
