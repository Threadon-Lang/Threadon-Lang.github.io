Hash

non-cryptographic hashes and checksums

What it does

Simple, deterministic hashes for strings and integers. The arithmetic stays in Int64 by reducing modulo the prime 1,000,000,007. They are useful for buckets, quick comparisons and checksums, but they are not cryptographic.

Example

A short program using the module:

import hash

def main() -> Int32
    print(hash.string_hash("hello"))
    print(hash.checksum16("hello"))
    return 0
299566379 1323

API

FunctionResult
string_hash(s)polynomial rolling hash, multiplier 31, starting at 7
djb2(s)djb2-style hash, multiplier 33
checksum16(s)16-bit reduction of string_hash
hash_int(x)hash of one Int32
hash_pair(a, b)order-sensitive hash of two integers
hash_list_int(xs)order-sensitive hash of an integer list

Notes and gotchas

  • Equal inputs always hash equally, but collisions are possible and easy to force.
  • Character codes come from strings.ord; only byte strings are supported.
