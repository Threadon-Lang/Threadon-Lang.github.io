URL

percent encoding and query strings

What it does

URLs and form bodies need characters such as spaces and ampersands escaped. This module provides quote/unquote for single values and encode_form/parse_query for dictionaries of text values.

Example

A short program using the module:

import url

def main() -> Int32
    print(url.quote("a b&c") == "a%20b%26c")
    print(url.unquote("a+b%2Fc") == "a+b/c")
    return 0
True True

API

FunctionResult
quote(s)percent-encode all but A-Za-z0-9-._~
unquote(s)decode %HH; + stays a plus
encode_form(d)query string from a Dict[String, String]
parse_query(q)query string to a Dict[String, String]

Notes and gotchas

  • Malformed percent escapes are kept literally instead of raising an error.
  • encode_form uses the dictionary's dict_key order, not sorted order.
