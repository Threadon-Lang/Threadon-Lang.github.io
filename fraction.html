Fraction

exact rational arithmetic

What it does

Fractions keep arithmetic exact by storing a numerator and denominator and reducing them with the greatest common divisor. The denominator is always positive, and a zero denominator is normalised to one.

Example

A short program using the module:

import fraction

def main() -> Int32
    a: fraction.Fraction = fraction.make(1, 2)
    b: fraction.Fraction = fraction.make(1, 3)
    print(fraction.to_string(fraction.add(a, b)) == "5/6")
    return 0
True

API

FunctionResult
make(n, d)normalised fraction; d == 0 becomes 1
add(a, b), sub(a, b)sum and difference
mul(a, b), div(a, b)product and quotient
to_float(a)approximate Float64 value
to_string(a)n/d, or just n for whole numbers

Notes and gotchas

  • Arithmetic uses Int64 and can overflow for large operands; keep values modest.
  • Division by a zero fraction returns 0/1, since an invalid denominator cannot be represented.
