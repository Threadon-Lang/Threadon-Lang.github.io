Table

plain-text tables and bars

What it does

Terminal output often needs aligned columns. table() measures every cell, pads each column and inserts a separator after the header row. The lower-level row, separator, pad_cell and bar helpers are available when you need more control.

Example

A short program using the module:

import table

def main() -> Int32
    print(table.separator([1, 2]) == "+---+----+")
    return 0
True

API

FunctionResult
pad_cell(s, width)left-aligned cell; long values end in ..
row(cells, widths)one | a | b | row
separator(widths)matching +---+---+ rule
bar(value, maximum, width, ch)fixed-width progress bar
table(rows)whole grid, with a separator after row 0

Notes and gotchas

  • Widths are byte counts, matching the language's len() and slicing.
  • Short rows get empty cells and extra cells are ignored.
