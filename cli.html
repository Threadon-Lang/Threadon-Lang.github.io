Threadon / CLI

CLI

the command-line compiler

Usage

Threadon is a Python module that drives LLVM. From the project root:

python3 -m threadon FILE.th [options]

With no options, the compiler prints LLVM IR to standard output.

Flags

FlagMeaning
-o FILEWrite the LLVM IR to FILE instead of stdout.
--runExecute the program with lli after compiling.
--exe FILEBuild a native executable via llc and gcc.
-I DIRAdd an import search path. Repeatable.
-O NOptimizer inline threshold. Default 0 = no inlining.
--debugEnable runtime checks. See the Debug page.
--flag-infFlag infinite (inf) and NaN float values: non-finite constants are a compile-time error and values that become non-finite at runtime raise a runtime error. Independent of --debug. Without it, non-finite values are allowed silently.

Entry point

Programs always start at main, and its return value becomes the exit code:

python3 -m threadon --run file.th

There is no flag to choose another function. If the compiled module has no main, running it or building an executable fails with "no function 'main' found in the compiled module".

Building an executable

--exe runs the IR through llc and links with gcc, so both need to be installed:

python3 -m threadon --exe hello examples/01_hello/main.th
./hello
