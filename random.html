Random

deterministic pseudo-random numbers

What it does

A small pseudo-random generator written entirely in Threadon. It uses a 31-bit linear congruential generator. The same seed always produces the same stream, which makes simulations and tests reproducible. It is not cryptographically secure and reads no entropy from the operating system.

Example

A short program using the module:

import random

def main() -> Int32
    random.seed(42)
    print(random.randint(1, 6))
    print(random.rand_float())
    return 0
4 0.519819

API

FunctionResult
seed(value)reset the module-level state
next_int()next Int64 in [0, 2**31)
randint(lo, hi)inclusive Int32 range; reversed bounds are swapped
rand_float()Float64 in [0, 1)
chance(percent)true with the given probability
choice_int(xs)one element of a List[Int32], or 0 when empty
shuffle_int(xs)Fisher-Yates shuffle of a copy of the list
dice(sides)roll from 1 to sides

Notes and gotchas

  • The state is module-level, so all importers share one stream.
  • The default seed is 42; call seed() if you need a different sequence.
  • Do not use this module for keys, tokens or anything security-sensitive.
