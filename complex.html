Complex

complex-number arithmetic

What it does

Threadon has no complex-number type, but a struct of two Float64 fields and a set of functions gets you most of the way. The functions return new values, so they compose naturally.

Example

A short program using the module:

import complex

def main() -> Int32
    z: complex.Complex = complex.make(3.0, 4.0)
    print(complex.norm(z) == 25.0)
    w: complex.Complex = complex.mul(z, z)
    print(complex.norm(w) == 625.0)
    return 0
True True

API

FunctionResult
make(re, im)build a Complex
add(a, b), sub(a, b)sum and difference
mul(a, b), scale(a, k)product and scalar multiple
conj(a)complex conjugate
norm(a), abs(a)squared magnitude and magnitude
to_string(a)human-readable re+imi text

Notes and gotchas

  • There is no operator overloading here: use the functions instead of + and *.
  • to_string trims the language's fixed six-decimal float output to one decimal.
