Stats

descriptive statistics

What it does

Descriptive statistics built on the lists and math modules. Variance is the population variance (divide by N, not N-1). Every function returns zero for an empty list.

Example

A short program using the module:

import stats

def main() -> Int32
    xs: List[Int32] = [2, 4, 4, 4, 5, 5, 7, 9]
    print(stats.mean_int(xs))
    print(stats.stddev_int(xs))
    return 0
5.000000 2.000000

API

FunctionResult
mean_int(xs), mean_float(xs)arithmetic mean
median_int(xs)median; average of the two middle values when even
variance_int(xs), variance_float(xs)population variance
stddev_int(xs), stddev_float(xs)square root of the variance
range_int(xs)largest minus smallest, as Int32
sum_float(xs), min_float(xs), max_float(xs)sum and extremes for float lists

Notes and gotchas

  • median_int sorts a copy, so the input list is unchanged.
  • Results are Float64, except range_int which is Int32.
