Bundled libraries

Besides the small std lib that is imported automatically, Threadon ships a set of opt-in modules. They are ordinary .th files in stdlib/, so no external toolchain is needed. Import one by name and call its functions qualified:

import math
import strings

def main() -> Int32
    print(math.gcd(48, 18))
    print(strings.upper("hello"))
    return 0
6 HELLO

Each page below documents one module. Every module also has a README.md next to its source and a test.th suite in the repository.

All libraries

Math

Integer and float math helpers: powers, factorials, gcd/lcm, rounding, square roots and constants.

Strings

String helpers for case conversion, trimming, searching, splitting, joining, replacing and padding.

Lists

Helpers for List[Int32] and List[String]: sums, extremes, searching, sorting, reversing and joining.

Random

A reproducible linear-congruential generator: seeds, integer and float draws, dice, choices and shuffles.

Bitops

AND, OR, XOR, NOT, shifts and bit counting for UInt32, built from division and modulo.

Stats

Means, medians, variance and standard deviation for integer and float lists.

CSV

Parse and encode CSV rows held in strings, with quoted fields and escaped quotes.

Path

Basename, dirname, extension, join and normalize for path strings — no filesystem access.

Hash

Deterministic polynomial and djb2 hashes for strings, integers and integer lists.

Vector

Vec2 and Vec3 structs with addition, dot and cross products, lengths, normalization and distances.

Containers

Functional stacks, queues and Dict-backed maps with String keys and values, built for Threadon's value semantics.

IntSet

A functional set with add, remove, union, intersection and difference.

Format

Hex and binary strings, zero padding, fixed decimals, percentages and thousands separators.

Using a module

The importer searches the -I directories, then the main file's folder, then the bundled stdlib/ directory. All four import forms work:

import math
import math as m
from math import gcd, is_prime
lazyimport random
lazyfrom stats import mean_int

Only functions, structs and classes can be imported. See Imports for the full rules. A library can import other libraries: stats, for example, uses lists and math.
