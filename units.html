Units

conversions and formatting

What it does

A collection of the conversions that come up most often: kilometres and miles, kilograms and pounds, Celsius and Fahrenheit, mebibytes and bytes, and seconds to H:MM:SS. Everything is plain arithmetic, with no lookup tables or external calls.

Example

A short program using the module:

import units

def main() -> Int32
    print(units.seconds_to_hms(3661) == "1:01:01")
    print(units.c_to_f(100.0) == 212.0)
    return 0
True True

API

FunctionResult
km_to_miles(v), miles_to_km(v)distance conversions
cm_to_inches(v)centimetres to inches
kg_to_pounds(v), pounds_to_kg(v)mass conversions
c_to_f(v), f_to_c(v)temperature conversions
seconds_to_hms(n)duration as H:MM:SS
mib_to_bytes(v), bytes_to_mib(n)binary data-size conversions

Notes and gotchas

  • MiB means 1,048,576 bytes, not one million bytes.
  • Results are Float64 unless the signature says otherwise; rounding is left to the caller.
