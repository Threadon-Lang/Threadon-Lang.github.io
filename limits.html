No loops

There is no for. The keywords is reserved, but writing it fails to compile. Repetition is done by recursion. Loops are the most requested missing feature.

Data structures

  • No strings beyond the basics. You can store them, print them, read them with input, and convert them to numbers, but there's no slicing, indexing, joining, or length.

Functions

  • No overloading. Two functions can't share a name, and imported names can collide.
  • No function values. You can't store a function in a variable or pass one to another function.
  • Functions must be defined before use in the file. There is no forward declaration.

Safety

  • Runtime errors need debug mode. Division by zero and bad string-to-number casts only error when you pass --debug; otherwise the behavior is undefined. See Debug.
  • Missing struct fields are garbage. Point(x=3) compiles and p.y is whatever memory happens to hold. See Structs.
  • Unary plus doesn't work
