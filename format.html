Format

numbers as text

What it does

Threadon prints floats with six decimals and has no printf-style formatting. This module adds hex and binary strings, zero padding, fixed-decimal rendering and thousands separators. Built on strings and math.

Example

A short program using the module:

import format

def main() -> Int32
    print(format.hex32(UInt32(255)))
    print(format.fixed(3.14159, 2))
    print(format.commas(1234567))
    return 0
ff 3.14 1,234,567

API

FunctionResult
hex32(x), bin32(x)lowercase hex / binary text for a UInt32
pad_int(v, width, pad), pad_float(v, width, pad)pad to a minimum width
fixed(x, decimals)float with a chosen number of decimals
percent(x, decimals)x * 100 with a percent sign
commas(n)integer with thousands separators

Notes and gotchas

  • fixed rounds half up; negative halves round towards zero, following math.round_f.
  • Padding uses the first byte of the pad string.
