CSV

comma-separated values in strings

What it does

A tiny RFC-4180-style CSV reader and writer. Threadon has no file I/O, so these functions work on strings from input() or literals. Fields are comma-separated; fields containing a comma, quote or newline are wrapped in quotes, and quotes inside them are doubled.

Example

A short program using the module:

import csv

def main() -> Int32
    fields: List[String] = csv.parse_line("\"Doe, Jane\",10")
    print(fields[0])
    print(csv.encode_line(fields))
    return 0
Doe, Jane "Doe, Jane",10

API

FunctionResult
parse_line(line)split one line into a List[String]
encode_field(s)quote one field only when needed
encode_line(fields)join encoded fields with commas
split_lines(text)split a multiline string on \n
get_field(line, index)one field, or "" when out of range

Notes and gotchas

  • A trailing newline in split_lines does not create an extra empty row.
  • Quoted fields may contain commas and doubled quotes; unquoted fields may not.
