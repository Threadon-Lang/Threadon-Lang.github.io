Checksum

small non-cryptographic digests

What it does

Checksums detect accidental changes to text or bytes. These are small, dependency-free implementations that stay in safe integer ranges by masking and reducing modulo fixed constants. They are not message authentication codes.

Example

A short program using the module:

import checksum

def main() -> Int32
    print(checksum.fnv1a("hello") == checksum.fnv1a("hello"))
    print(checksum.adler32("hello") > 0)
    return 0
True True

API

FunctionResult
fnv1a(s)32-bit FNV-1a as an Int64
adler32(s)Adler-32 reduced modulo 65521
crc8(s)8-bit CRC with polynomial 0x07
checksum_bytes(xs)FNV-1a over a byte List[Int32]

Notes and gotchas

  • Different inputs can collide; these functions are for quick sanity checks, not security.
  • There is no bitwise XOR operator in Threadon, so the implementations use division and modulo instead.
