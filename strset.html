String set

sets of strings

What it does

The intset module covers integers; this one does the same job for strings. A StringSet keeps insertion order and all operations return a new set, leaving their arguments untouched.

Example

A short program using the module:

import strset

def main() -> Int32
    s: strset.StringSet = strset.from_list(["a", "b", "a"])
    print(strset.size(s) == 2 and strset.contains(s, "b"))
    return 0
True

API

FunctionResult
empty_set()a new empty set
from_list(xs)set of the distinct strings in a list
to_list(s), size(s)values in insertion order, and item count
contains(s, value)membership test
add(s, value), remove(s, value)new sets with the value added or removed
union(a, b), intersection(a, b), difference(a, b)set operations, always returning a new set

Notes and gotchas

  • Comparison is byte-for-byte: "A" and "a" are different values.
  • Classes and lists have value semantics in Threadon, so a mutating method would not update the caller's set; functions are used instead.
