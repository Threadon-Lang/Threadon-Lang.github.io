Base64

encode bytes as ASCII

What it does

Base64 turns bytes into printable ASCII. Threadon strings are byte strings, so this module works on one-byte characters and on List[Int32] values in the range 0..255. Encoding adds = padding; decoding ignores whitespace and stops at the first =.

Example

A short program using the module:

import base64

def main() -> Int32
    print(base64.encode("hello") == "aGVsbG8=")
    print(base64.decode("aGVsbG8=") == "hello")
    return 0
True True

API

FunctionResult
encode(s)base64 text for a String
decode(s)decoded String; invalid characters become byte 0
encode_bytes(xs)base64 text for a List[Int32] of bytes
decode_bytes(s)bytes as a List[Int32]

Notes and gotchas

  • Use the byte helpers when the data contains zero bytes: len() stops at the first NUL in a String.
  • This is encoding, not encryption: anybody can decode it.
